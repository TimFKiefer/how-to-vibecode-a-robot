Every part you need to build it

Takt is built in public and fully vibecoded: Tim directs, AI coding agents (Claude Code) write the code. Fully vibe-codable: you can do it yourself. This list came about the same way: an AI agent read the shops and wrote the list down, and a script adds up the sums, not a person.

3 · Before the full set

The fit test comes first

No size in the model is checked yet. So the parts are printed in two steps. You need three servos in hand for it: that is how many one leg has.

  1. Print the fit test

    The fit gauge and the fit collar, two small test pieces for the seat of the servos, and one whole leg.

  2. Check that it fits

    Put the three servos in. The fit test mostly changes printed parts. On the shopping list it can change small things: cable extensions, inserts, screws.

  3. Then the full set

    Only when servo and parts fit together, print the full set: the body (4 parts) and six legs (30 parts).

Own printer? It needs a print area of at least about 160 x 160 mm, a print height of at least about 80 mm, a nozzle up to 255 °C, a heated bed up to 75 °C, a direct extruder, 1.75 mm filament and a 0.4 mm nozzle. It does not need an enclosure.
